# Sensor Data Analysis with SQLite

This folder contains the data analysis extension for the Embedded Environmental Data Logger project.

The embedded system logs temperature and humidity readings to a microSD card as CSV records. This analysis workflow is designed to import those CSV records into a SQLite database and run SQL queries to summarize sensor behavior.

## Files

- `sample_sensor_data.csv`: sample CSV data generated by the embedded data logger
- `queries.sql`: SQL queries for analyzing logged sensor records

## Example CSV Format

```csv
time_ms,temperature_c,humidity_percent,alert_status,checksum
2012,23.90,47.00,OFF,29
4012,24.10,48.00,OFF,33
